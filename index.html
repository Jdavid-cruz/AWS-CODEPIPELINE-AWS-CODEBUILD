🚀 Mi Pipeline CI/CD en AWS

Cómo configuré un flujo de despliegue automático usando CodePipeline, CodeBuild y S3

📋 Qué he implementado

Un pipeline automatizado que:

  1. Detecta cambios en GitHub (push)
  2. Construye la aplicación usando CodeBuild
  3. Despliega los cambios en un bucket S3

🔧 Pasos técnicos detallados

1. Configuración inicial en AWS

  • Creado bucket S3 con hosting web habilitado
  • Configurado permisos públicos (Bucket Policy)
  • Subido manualmente los archivos iniciales

2. Integración con GitHub

  • Creado conexión OAuth en AWS CodePipeline
  • Seleccionado repositorio y rama (main)
  • Configurado webhook para detectar cambios

3. Configuración de CodeBuild

  • Creado archivo buildspec.yml:
    • version: 0.2
phases:
  build:
    commands:
      - echo "Build started"
      - aws s3 sync . s3://mi-bucket --delete
  • Seleccionado entorno estándar: Amazon Linux 2

4. Permisos IAM

  • Creado rol para CodeBuild con permisos para S3
  • Política adjuntada: AmazonS3FullAccess
  • Verificado que el servicio de confianza es CodeBuild
