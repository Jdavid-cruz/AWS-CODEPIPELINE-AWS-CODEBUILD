Pipeline CI/CD en AWS

Implementación automatizada usando CodePipeline, CodeBuild y S3

AWS DevOps CI/CD

Descripción del Proyecto

Este proyecto demuestra la implementación de un pipeline básico de CI/CD (Integración Continua/Despliegue Continuo) en AWS, configurado completamente desde la consola de administración de AWS. El objetivo es automatizar el despliegue de cambios en un sitio web estático cada vez que se actualiza el repositorio de GitHub.

¿Cómo funciona? Cuando hago un push a GitHub, AWS detecta el cambio, construye la nueva versión y la despliega automáticamente en un bucket S3 configurado para hosting web.

Pasos Implementados

Paso Qué hicimos Servicio AWS
1 Creamos un bucket S3 para alojar el frontend Amazon S3
2 Configuramos el bucket para hosting web estático Amazon S3
3 Creamos un repositorio en GitHub con nuestro código GitHub
4 Creamos un pipeline en CodePipeline AWS CodePipeline
5 Configuramos CodeBuild con buildspec.yml AWS CodeBuild
6 Dimos permisos IAM para que CodeBuild pudiera subir a S3 AWS IAM
7 Automatizamos todo el flujo: (push) → (build) → (deploy) Todos los anteriores

Arquitectura del Pipeline

Diagrama simplificado del pipeline CI/CD en AWS

  1. Fuente (Source)
    CodePipeline detecta cambios en el repositorio de GitHub
    1
  2. Construcción (Build)
    CodeBuild ejecuta las instrucciones del archivo buildspec.yml
    2
  3. Despliegue (Deploy)
    Los archivos construidos se copian al bucket S3 configurado para hosting web
