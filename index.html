🔍 Sobre este proyecto

Este es un laboratorio práctico que demuestra un flujo básico de CI/CD en AWS:

  1. El código fuente se aloja en GitHub
  2. AWS CodePipeline detecta cambios mediante webhook
  3. AWS CodeBuild procesa los archivos según buildspec.yml
  4. Los artefactos se despliegan automáticamente en un bucket S3
💡 Nota: Cada git push en la rama principal activa el pipeline completo.

⚙️ Configuración técnica

1. Bucket S3

  • Hosting web estático habilitado
  • Política de bucket pública configurada
  • Acceso directo via URL de S3

2. Pipeline AWS

  • Origen: Conexión con repositorio GitHub
  • Etapa de build con CodeBuild
  • Despliegue automático a S3

3. Archivo buildspec.yml

version: 0.2
phases:
  build:
    commands:
      - echo "Iniciando construcción..."
      - aws s3 sync . s3://$S3_BUCKET --delete
